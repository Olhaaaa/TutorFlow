# Рішення (ADR)

Контекст → рішення → наслідки → розглянуті альтернативи. Пишеться в момент
рішення, а не перед звітом: остання секція доводить, що вибір зроблений, а не
вгаданий, і відтворити її через два тижні вже неможливо.

Номер — порядок видачі, не хронологія. Вісім записів на лабу 1, поділені
навпіл між вертикалями: **A — Розклад**, **B — Гроші й канали**. Далі — по
одному на кожне рішення лаби 2.
