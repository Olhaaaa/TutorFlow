# API Tutorflow

Перелік усіх маршрутів сервісу `api`. Живий, із формою «спробувати» — Swagger:

- розгорнуто: https://tutor-flow-cloud.duckdns.org/api/docs (JSON — `/api/docs-json`)
- локально: http://localhost:8080/api/docs

Цей файл — огляд для звіту й для того, хто не хоче відкривати Swagger. Якщо
вони розходяться, правий Swagger: він будується з коду.

## Загальні правила

| | |
|---|---|
| Префікс | усі маршрути під `/api`, крім `/healthz` |
| Формат | JSON у тілі й відповіді, крім стрічок `.ics` |
| Вхід | `POST /api/auth/login` → `{ token }`; далі заголовок `Authorization: Bearer <token>` |
| Ролі | у токені зашита роль: **студент** або **викладач**. Маршрут не тієї ролі відповідає 401 |
| Гроші | цілими **копійками** (`amountMinor: 50000` = 500 ₴) |
| Час | ISO 8601 в **UTC** (`2026-10-20T09:00:00Z`); у зону користувача переводить клієнт. Виняток — `startTime` у шаблоні викладача: це настінний час викладача, `HH:mm` |
| День тижня | `weekday`: 0 — неділя … 6 — субота |
| Валідація | зайві поля в тілі відкидаються; невалідні — 400 з переліком помилок |

Демо-облікові записи після сідера (пароль у всіх `tutorflow`):
`teacher@tutorflow.local` — викладач; `anya@`, `bohdan@`, `vira@tutorflow.local` — студенти.

Позначення в таблицях: **Хто** — 🔓 без входу, **С** — студент, **В** — викладач,
**С/В** — будь-хто з входом.

## Вхід і профіль

| Метод | Шлях | Хто | Що робить |
|---|---|---|---|
| POST | `/api/auth/login` | 🔓 | Вхід. Тіло `{ email, password }` → `{ token, role, id, name, timezone }`. Невірні дані — 401 |
| GET | `/api/me` | С/В | Хто я за поточним токеном: роль, ім'я, часовий пояс |
| PATCH | `/api/me/timezone` | С/В | Змінити свій часовий пояс. Тіло `{ timezone: "Europe/Kyiv" }` (IANA). Наявні заняття не зсуваються — змінюється лише відображення |

## Розклад: студент

| Метод | Шлях | Хто | Що робить |
|---|---|---|---|
| GET | `/api/slots?from=&to=` | С | Календар на період. Чужі заняття — просто `busy`, без імені й статусу |
| GET | `/api/slots/available?from=&to=` | С | Лише ті години, які справді можна забронювати (з урахуванням зайнятості викладача поза розкладом) |
| POST | `/api/slots/:id/book` | С | Забронювати. Вистачає балансу → `booked`; ні → `pre_booked` із дедлайном оплати. Слот уже зайнятий — 409 |
| POST | `/api/slots/:id/cancel` | С | Скасувати. `pre_booked` — завжди безкоштовно; `booked` — безкоштовно не пізніше ніж за `cancelHours` (24 год, межа включна), пізніше — без повернення. Чуже заняття — 403 |
| POST | `/api/slots/:id/reschedule` | С | Перенести на інший слот однією операцією. Тіло `{ toSlotId }`. Ті самі межі, що й у скасуванні; оплата переїжджає разом із заняттям. Цільовий слот зайнятий — 409 |
| GET | `/api/student/calendar-link` | С | Адреса особистої стрічки `.ics` (створюється при першому зверненні) |
| DELETE | `/api/student/calendar-link` | С | Відкликати стрічку — стара адреса перестає працювати одразу |

## Розклад: викладач

| Метод | Шлях | Хто | Що робить |
|---|---|---|---|
| GET | `/api/teacher/slots?from=&to=` | В | Власний розклад із сирими статусами й іменами студентів |
| POST | `/api/teacher/slots/:id/cancel` | В | Скасувати заняття. Кошти повертаються студенту повністю, правило `cancelHours` не діє |
| POST | `/api/teacher/slots:generate` | В | Розгорнути тижневий шаблон у слоти. Тіло `{ weeks?: 1…26 }`, типово 4. Ідемпотентно: повтор не дублює години. **Двокрапка — частина шляху**, це не параметр |
| GET | `/api/teacher/availability` | В | Тижневий шаблон доступності |
| POST | `/api/teacher/availability` | В | Додати годину в шаблон. Тіло `{ weekday, startTime: "16:00", durationMin: 15…480, priceMinor }` |
| DELETE | `/api/teacher/availability/:id` | В | Прибрати годину з шаблону; майбутні **вільні** слоти зникають, записані лишаються |
| GET | `/api/teacher/busy?from=&to=` | В | Інтервали зайнятості поза розкладом |
| POST | `/api/teacher/busy` | В | Позначити себе зайнятим. Тіло `{ startAt, endAt, title? }`. Вільні слоти в інтервалі перестають бронюватись; записані заняття не скасовуються |
| DELETE | `/api/teacher/busy/:id` | В | Прибрати інтервал зайнятості |
| GET | `/api/teacher/enrollments` | В | Постійні місця студентів (хто, день, година) |
| POST | `/api/teacher/enrollments` | В | Закріпити студента за годиною. Тіло `{ studentId, weekday, startTime }`. Майбутні вільні слоти цієї години стають `pre_booked` |
| DELETE | `/api/teacher/enrollments/:id` | В | Зняти закріплення; майбутні неоплачені слоти звільняються |
| GET | `/api/teacher/calendar-link` | В | Адреса стрічки `.ics` викладача |
| DELETE | `/api/teacher/calendar-link` | В | Відкликати стрічку |

## Стрічки календаря (`.ics`)

Без входу: календарні програми не вміють передавати токен, тому секрет — у самій
адресі. Адресу видають маршрути `…/calendar-link` вище.

| Метод | Шлях | Хто | Що робить |
|---|---|---|---|
| GET | `/api/calendar/:token` | 🔓 | Стрічка викладача (iCalendar). `.ics` у кінці необов'язкове. Невідомий токен — 404 |
| GET | `/api/calendar/student/:token` | 🔓 | Стрічка студента — лише його заняття |

## Гроші

| Метод | Шлях | Хто | Що робить |
|---|---|---|---|
| GET | `/api/balance` | С | Баланс, останні операції й сума, якої бракує на закріплені заняття |
| GET | `/api/balance/history?direction=in\|out` | С | Історія операцій; `in` — поповнення й повернення, `out` — списання |
| GET | `/api/teacher/students` | В | Студенти з балансами |
| POST | `/api/teacher/students` | В | Додати студента. Тіло `{ name, email, timezone, password }` |
| POST | `/api/teacher/students/:id/topup` | В | Поповнити баланс вручну. Тіло `{ amountMinor ≥ 1, comment? }`. У відповіді — заняття, які одразу стали оплаченими |
| GET | `/api/teacher/students/:id/audit` | В | Звірка кешованого балансу з журналом транзакцій. Розбіжність = помилка в коді |

## Оплата карткою (monobank)

| Метод | Шлях | Хто | Що робить |
|---|---|---|---|
| GET | `/api/payments/options` | С | Чи може цей студент платити карткою (чи підключив викладач еквайринг) |
| POST | `/api/payments` | С | Створити рахунок. Тіло `{ amountMinor ≥ 100 }` → посилання на сторінку оплати. Баланс змінює **вебхук**, а не повернення зі сторінки. Еквайринг не налаштований — 503 |
| GET | `/api/payments/:id` | С | Статус платежу — для сторінки повернення, яка опитує, доки статус не остаточний. Чужий платіж — 403 |
| GET | `/api/payments/teacher/connection` | В | Чи підключений власний рахунок викладача |
| POST | `/api/payments/teacher/connection` | В | Підключити рахунок. Тіло `{ token }` — токен еквайрингу; перевіряється в monobank і зберігається зашифрованим. Невалідний — 400 |
| DELETE | `/api/payments/teacher/connection` | В | Відключити рахунок |
| POST | `/api/payments/monobank/callback` | 🔓 | **Вебхук monobank.** Не для людей і не в Swagger. Замість входу — підпис `X-Sign` над сирим тілом |

## Службове

| Метод | Шлях | Хто | Що робить |
|---|---|---|---|
| POST | `/api/teacher/maintenance` | В | Застосувати переходи станів зараз (звільнити протерміновані закріплення, закрити проведені заняття, протермінувати рахунки), не чекаючи воркера |
| GET | `/healthz` | 🔓 | Перевірка живості: `{ status: "ok", db: "up" }`; без бази — `degraded`. Поза `/api` — з нього бере перевірку балансувальник |
| GET | `/api/docs` | 🔓 | Swagger UI |

## Приклад

```bash
BASE=https://tutor-flow-cloud.duckdns.org

TOKEN=$(curl -s -X POST $BASE/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"anya@tutorflow.local","password":"tutorflow"}' | sed -E 's/.*"token":"([^"]+)".*/\1/')

curl -s "$BASE/api/slots/available?from=2026-10-20T00:00:00Z&to=2026-10-27T00:00:00Z" \
  -H "Authorization: Bearer $TOKEN"

curl -s -X POST $BASE/api/slots/42/book -H "Authorization: Bearer $TOKEN"
```
